About the Project

Health360 is a healthcare analytics project created to visualize and explore healthcare dataset information using Tableau Public.

  • Patient demographics and age distribution
  • Medical conditions and medications
  • Admission types and test results
  • Hospital-wise billing trends

The dashboard supports exploratory analysis of the available data. It is intended for educational and informational purposes, not for medical diagnosis.
